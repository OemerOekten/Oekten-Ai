# Ökten Intelligence · Website

Statische One-Page-Website für Ökten Intelligence (KI-Beratung für den Mittelstand, Tuttlingen).
Reines HTML, CSS und JavaScript, ohne Build-Schritt.

- `index.html`: die Seite (Scroll-Hero auf Desktop, Standbild-Hero auf Handy und Tablet)
- `impressum.html`, `datenschutz.html`: Rechtliches (Platzhalter in eckigen Klammern noch ausfüllen)
- `assets/`: Bilder (KI-generiert) und selbst gehostete Schriften (Sora, Manrope, JetBrains Mono)
- `cryptopro/index.html`: CryptoPro Terminal, eigenständige Seite (russische Oberfläche) mit Live-Kursen, Arbitrage über 8 Börsen nach Gebühren, technischen Signalen, Memecoins (GeckoTerminal) und Preis-Zielen

Lokale Vorschau: `python3 -m http.server` im Ordner starten und `http://localhost:8000` öffnen.
